# 多维数据探查分析工具

离线版多维数据探查分析工具，涵盖数据源接入、交互查询、聚合统计、图表看板、预警通知与数据导出，所有分析配置与结果持久化到浏览器本地存储。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 预警通知的阈值判定

预警通知页面不只维护规则，还会读取异常检测结果里的「当前指标值」，按规则上下界与静默窗口生成
**预警通知记录数据明细**。判定口径集中在这几个文件：

- `frontend/src/data/alert-rules.ts`：阈值解析、越界判定、级别取舍与保存前校验（纯函数）。
- `frontend/src/api/alert-service.ts`：阈值判定、活动告警更新、通知明细与判定事件流水。
- `frontend/src/api/alert-export.ts`：明细 CSV 与完整台账 JSON 导出。
- `frontend/src/data/alert-store.ts`：明细台账的 localStorage 持久化（与规则数据分开存放）。

判定约定：

1. **阈值判定**：指标值高于上界或低于下界才算越界，`下界 < 上界` 之外的条件不允许保存；启用规则前
   也会再校验一次，避免越界条件进入可判定状态。
2. **静默窗口**：同一指标同一时刻只有一条活动告警。静默期内的重复越界只更新那条活动告警并生成一条
   标记为「静默更新」的明细，不会再起一条告警。
3. **并发只生效一次**：每份检测结果有唯一编号，重复投递时只有第一次生效；同一判定分钟内再次越界只
   更新活动告警，不新增通知明细。恢复只通知一次，乱序到达的旧检测结果只记事件不重算。
4. **多规则冲突**：同一指标同时命中多条规则时，按告警级别（同级按覆盖区间）选一条主告警，其余规则
   各自生成「冲突保留」明细，保留自己的规则版本、阈值上下界与取舍说明。
5. **版本与回查**：每条明细固化 `规则编号@规则版本`、阈值上下界与明细版本；调整阈值只影响后续判定，
   历史明细不被改写。明细页的「核对来源」可以直接看到原始规则、阈值依据、指标值、静默状态与活动告警。
6. **导出与列表一致**：明细表、CSV 与台账 JSON 共用同一份筛选后的读模型，台账 JSON 还会带上
   `schemaVersion` 与 `detailVersion`，保存到文件后仍能核对版本。

示例数据里 `ANOM-0003` 的「库存水位」指标值为 `170`，同时越过 `ALER-0001`（上界 160，版本 v1）与
`ALER-0002`（上界 150，版本 v2）的边界；在预警通知页点一次「按此结果判定」即可看到两条各自带阈值
依据的明细、一条活动告警，以及同一分钟再次判定不新增告警的效果。

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `data-explore-studio:entries` 这一项，或调用 `resetModule(模块)`；
  预警通知明细台账独立存在 `data-explore-studio:alert-ledger`，清掉它或点页面上的「重置判定台账」只
  清通知与活动告警，不动规则数据。
